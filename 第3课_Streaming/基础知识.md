# 第3课：Streaming 流式输出

## 这节课解决什么问题

第2课实现了 Function Calling，但有个明显问题：AI 回答要**等全部生成完才显示**。

实际产品里，ChatGPT、通义、文心一言都是一个字一个字"打"出来的——这就是流式输出。

对前端工程师来说，这节课是 **必须掌握的**：
- 后端怎么把内容一段一段发出来（SSE）
- 前端怎么逐字渲染

---

## 流式输出的原理

```
传统请求：用户等 3 秒 → 一次性收到完整回答

流式请求：用户发请求 → 0.2s 收到第一个字 → 持续收到后续字 → 结束
```

背后的协议叫 **SSE（Server-Sent Events）**：
- 服务端保持连接不关
- 每有新内容，发一行 `data: {...}`
- 发完了，发 `data: [DONE]`

前端用 `EventSource` 或 `fetch` + `ReadableStream` 接收。

---

## Demo 代码

本课无需新增包，流式输出是 LangChain 内置能力。

```python
import sys
import json
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from utils import get_llm

from langchain_core.messages import HumanMessage

llm = get_llm()


# ① 基础流式输出：逐字打印
def stream_basic(prompt: str):
    print(f"\n用户: {prompt}")
    print("AI: ", end="", flush=True)

    for chunk in llm.stream([HumanMessage(prompt)]):
        print(chunk.content, end="", flush=True)

    print()


# ② 流式输出 + 收集完整内容（实际项目常用）
def stream_and_collect(prompt: str) -> str:
    print(f"\n用户: {prompt}")
    print("AI: ", end="", flush=True)

    full_content = ""
    for chunk in llm.stream([HumanMessage(prompt)]):
        print(chunk.content, end="", flush=True)
        full_content += chunk.content

    print()
    return full_content


# ③ 模拟 SSE 格式：展示后端真实发给前端的数据长什么样
def stream_as_sse(prompt: str):
    print(f"\n用户: {prompt}")
    print("--- 模拟 SSE 输出（后端 → 前端） ---")

    for chunk in llm.stream([HumanMessage(prompt)]):
        if chunk.content:
            data = json.dumps({"delta": chunk.content}, ensure_ascii=False)
            print(f"data: {data}")

    print("data: [DONE]")


if __name__ == "__main__":
    stream_basic("用一句话解释什么是流式输出")

    full = stream_and_collect("用三句话介绍 Function Calling")
    print(f"\n[完整内容共 {len(full)} 字]")

    stream_as_sse("你好")
```

关键：每个 `chunk.content` 就是一小段文字，前端每收到一段就追加到界面上。

## 3 个核心概念

### 1. `stream()` vs `invoke()`

```python
# invoke：等全部生成完，返回一个完整对象
response = llm.invoke([HumanMessage("你好")])
print(response.content)

# stream：返回一个迭代器，每次迭代拿到一个 chunk
for chunk in llm.stream([HumanMessage("你好")]):
    print(chunk.content, end="", flush=True)
```

`flush=True` 是必须的，否则终端缓冲会导致内容积攒后一次性刷出来，看不到逐字效果。

### 2. chunk 的结构

```python
for chunk in llm.stream([HumanMessage("你好")]):
    print(type(chunk))        # AIMessageChunk
    print(chunk.content)      # 这次的文字片段，可能是 "" 空字符串（首尾 chunk）
    print(chunk.response_metadata)  # 最后一个 chunk 会有 finish_reason 等信息
```

实际使用时只需要 `chunk.content`，空字符串跳过即可。

### 3. SSE 协议格式

```
Content-Type: text/event-stream

data: {"delta": "你好"}\n\n
data: {"delta": "，有什么"}\n\n
data: [DONE]\n\n
```

每条消息是 `data: <内容>\n\n`（两个换行），最后 `[DONE]` 表示结束。不同厂商的字段名可能不同（OpenAI 用 `delta`，有些用 `text`），前端解析时要看文档。

## 后端到前端完整链路

### Python 后端（FastAPI）

```python
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from langchain_core.messages import HumanMessage

app = FastAPI()


@app.get("/chat")
async def chat(prompt: str):
    async def generate():
        for chunk in llm.stream([HumanMessage(prompt)]):
            if chunk.content:
                data = json.dumps({"delta": chunk.content}, ensure_ascii=False)
                yield f"data: {data}\n\n"
        yield "data: [DONE]\n\n"

    return StreamingResponse(generate(), media_type="text/event-stream")
```

### 前端 JS 接收

```javascript
// 方法一：EventSource（只支持 GET）
const source = new EventSource(`/chat?prompt=${encodeURIComponent(userInput)}`);
source.onmessage = (e) => {
  if (e.data === "[DONE]") {
    source.close();
    return;
  }
  const { delta } = JSON.parse(e.data);
  outputEl.textContent += delta;  // 追加到界面
};

// 方法二：fetch + ReadableStream（支持 POST，更灵活）
const resp = await fetch("/chat", {
  method: "POST",
  body: JSON.stringify({ prompt: userInput }),
  headers: { "Content-Type": "application/json" },
});

const reader = resp.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;

  const lines = decoder.decode(value).split("\n\n");
  for (const line of lines) {
    if (!line.startsWith("data: ") || line === "data: [DONE]") continue;
    const { delta } = JSON.parse(line.slice(6));
    outputEl.textContent += delta;
  }
}
```

## 和非流式的对比

| | `invoke()` | `stream()` |
|---|---|---|
| 响应方式 | 等全部生成完，一次性返回 | 边生成边返回 chunk |
| 用户体验 | 白屏等待 | 逐字出现，有"思考感" |
| 后端实现 | 普通 HTTP 响应 | SSE / chunked transfer |
| 前端实现 | 普通 `fetch` | `EventSource` 或 `fetch + ReadableStream` |
| 适合场景 | 批处理、不展示给用户 | 几乎所有对话 UI |
